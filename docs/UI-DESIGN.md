# 界面设计规范

界面先行的落地依据。M1 全部用假数据实现本文件；M4 只替换数据来源，不改布局。

> **实现说明（2026-11-22）**：唯一实现是 `src/Xdm.Ui.Mew`（MewUI，code-first，Win32 + Direct2D）。
> 本文件早期按 Avalonia 版（已删除）写的实现细节（`*.axaml`、Fluent 资源字典、`x:Class`）已不再适用，
> **视觉与交互规范仍然有效**，实现手段以 §12 的对照表为准。

## 1. 设计基调

- 组件库：`Aprillz.MewUI` 自带控件 + `MewTheme` 统一色值与尺寸（无资源字典、无换肤）。
  不做重型自定义控件外观。
- 风格：信息密度优先（类 IDM / XDM 桌面端），行高 56，字号 12–13，圆角 4。
- 明暗主题跟随系统，色值集中在 `MewTheme`，另有 4 个语义色：
  `Progress`（主色）、`Success`、`Warn`、`Error`。`MewThemeTests` 钉住色值与尺寸。

├───────────────┬──────────────────────────────────────────────────────────────┤

├───────────────┴──────────────────────────────────────────────────────────────┤

- 左栏固定 180px，可折叠；列表区用**虚拟化**容器。
- 列表技术选型（**已定案**）：`ListBox` 只按可见区绘制（MewUI 不为每行建元素，虚拟化是默认行为）。
  两行式行本来不吃列布局，**不要**为了列头/列宽引入表格控件；真要排序就在 ViewModel 排完重建集合。
- 行高与内边距必须走 `MewTheme`（`RowHeight = 56`），不要在行构建里写字面量——
  `LayoutTests` 会拿它和规范比对。
- 工具栏右侧：[⚙ 设置] [关于] [退出]，`Button.tool` 样式。**退出必须确认**：
  `MainWindow.ConfirmOnExit = true`（组合根设置）时，点「退出」与关窗口（标题栏关闭键 / Alt+F4）
  都走 `ConfirmDialog`，文案带进行中任务数（`MainWindowViewModel.ActiveCount`），
  确认后才真正 `Close()`；取消则窗口保持。无头测试不设该开关，避免模态框挂住用例。

### 3.1 按钮图标

所有带文字的按钮统一「**12px 矢量图标 + 5px 间距 + 文本**」，不用 emoji 字形
（`⚙` / `🗑` 这类彩色字形在 125%/175% DPI 下发糊，且依赖 Segoe UI Emoji 的渲染差异）。

| 按钮 | 图标（Material Design Icons，24×24 viewBox） |
|---|---|
| 新建 | `plus` |
| 恢复 | `play` |
| 暂停 | `pause` |
| 删除 | `delete`（垃圾桶） |
| 设置 | `cog` |
| 关于 | `information`（圆 i） |
| 退出 | `logout`（门 + 右箭头） |
| 取消 | `close`（✕） |
| 关闭 | `close`（✕，与「取消」同款；关于窗口、设置窗口） |
| 确定 | `check`（✓） |
| 标题栏最小化 / 最大化 / 关闭 | 见 §11.1，1px 线宽几何，与系统窗钮同观感 |

实现约束：

- 图标用 `PathShape` 画矢量（`StrokeThickness` 必须显式给，MewUI 默认 0 会"看不见"）。
  颜色跟着主题 token 走，禁用态用 `MewTheme.DisabledForeground`，**不要**写死色值。
- 按钮装的是「图标 + 文本」横向栈时，测试里别指望自动取到文案——断言走
  `VisualTree.Texts`（它会同时读 `TextBlock.Text` 与 `AccessText.RawText`）。
- 行内悬停按钮（暂停/目录/删除）保持纯文字 11px：行高只有 56，加图标会挤，且是次要操作。

## 4. 列表行规范（`MainWindow.cs` 的行构建 + `Controls/RowHost.cs`）

两行式，高 56，内边距 12/8。列结构（`RowHost.Columns`）：**三角位 14 · 图标 26 · 名称 Star · 右侧 360**。

| 区域 | 内容 | 说明 |
|---|---|---|
| 展开三角 14 | 只有多文件任务父行显示（9×9 描边三角，收起朝右、展开朝下） | 点击展开/收起子文件行；普通行这一列隐藏，内容整体左移 |
| 左图标 26 | 文件类型图标（按扩展名）+ 状态角标 | 下载中角标为旋转箭头，暂停为 ⏸，失败为 ⚠ |
| 第一行 | 文件名（省略号截断，Tooltip 全名） | 字号 13，`TextTrimming=CharacterEllipsis` |
| 第一行右 | 大小 / 已完成时间 | 右对齐，次要色 |
| 第二行 | 进度条 + 百分比 | 进度条高 4，圆角 2；完成态隐藏 |
| 第二行中 | `x/y 段 · 目标文件夹` | 次要色 11px |
| 第二行右 | 速度 + 剩余时间 | `24.3 MB/s` / `约 1 分 12 秒` |
| 悬停 | 右侧浮现 [暂停/恢复] [目录] [删除] 三个图标按钮 | 悬停才显示，避免视觉噪声 |

状态徽标色：

| 状态 | 颜色 | 文案 |
|---|---|---|
| 下载中 | `ProgressBrush` | `下载中`（百分比与段数在第二行：`76%  3/12 段`，徽标不重复） |
| 暂停 | 次要灰 | `已暂停` |
| 连接中 | 次要灰 + 呼吸 | `正在连接…` |
| 完成 | `SuccessBrush` | `已完成` |
| 失败 | `ErrorBrush` | `失败：连接被重置` |
| 磁盘错误 | `WarnBrush` | `磁盘空间不足` |

进度刷新约束：`Progress` 值变化 ≥ 1% 才更新绑定；文字（速度/剩余）250ms 一次。
自定义 `SegmentBar`（分段条）用 `DrawingContext` 直绘，不复用 `ProgressBar` 控件（减少视觉树与布局开销）。

### 4.1 多协议 / 多文件的行呈现（V2 HF 已启用，V3 BT 沿用）

多文件任务（HF 模型包）在引擎里是「父行 + 子行」两层。列表默认**只渲染父行**，父行行首的三角
可以把子文件行展开在同一列表里（`MainWindowViewModel.ToggleExpand`）：

| 项 | 表现 |
|---|---|
| 父行（模型包 / torrent） | 文件名 = `owner/name`；进度/速度/大小 = Σ 子文件；第二行中显示 `3/12 个文件 · D:\Downloads`；图标标签「包」；行首三角可点 |
| 子行（展开后） | 紧跟父行、行高同为 56；三角位留空形成 **14px 缩进**；名称是包内相对路径（如 `model-00001-of-00004.safetensors`），第二行 `3/4 段 · 目录`；悬停按钮照旧（暂停/目录/删除都作用于**这一个文件**） |
| 收起 | 子行从集合里摘掉，不占位；引擎推来的子任务进度直接忽略（父行汇总已含） |
| 徽标文案 | 父行同样 `下载中` / `已完成` / `部分文件失败`，不要把子行状态搬上来 |
| 详情窗口 | 父任务显示"文件网格"（每格一个文件），点格子进子任务的分段条（未做） |

约束：
- 子行**不是独立任务**：不进 `_all`、不进分类计数、不进「显示 N / 共 M 个任务」（`ListSummary` 只数父行）。
  它只是把父行的子任务快照铺开给人看。
- 展开状态由 `MainWindowViewModel._expanded`（父 id → 子行）持有，换分类/改搜索词重建 `Rows` 后跟着
  父行原位恢复；父行被删除时整段一起消失。
- `DownloadRowViewModel` 的字段（`Progress` / `SizeText` / `SpeedText` / `StatusText` / `IsParent` /
  `IsContainer` / `IsExpanded` / `CanExpand`）保持不变，父行只是把「段」换成「个文件」。
- 演示模式（`XDM_DEMO`）第 4 行是预置模型包，`SampleDownloads.Children` 供数据；真实运行只走
  `IDownloadActions.Children`（引擎快照）。

## 6. 新建下载窗口

固定尺寸 620×600（不可缩放）：标题栏 / 页签（高 320）/ 共用字段 / 底部按钮四段。

### 6.1 页签

| 页签 | 字段 |
|---|---|
| 链接 | 链接（`EditBox`，多行批量）、文件名（可空，空则自动推导） |
| HuggingFace | 模型 id / 关键字（`EditBox`）+ [搜索] + [拉取文件]、版本（revision，默认 `main`）、文件列表（`ListBox`，多选，行显示路径 + 大小）、[全选] / [全不选]、状态行 |

「搜索」把输入框内容当关键字打 `/api/models?search=…`（后台线程），结果在文件列表同一位置顶替显示
（行显示 `owner/name` + 下载量 + 任务类型）；点一条即填入模型 id 并自动拉该模型的清单，列表切回文件模式。
结果模式下点「添加」会被拦下（此时文件清单还是上一个仓库的，勾选会串）。

「拉取文件」把清单请求放后台，结果回 UI 线程填列表并默认全选；失败时状态行写中文原因
（网络/超时/401/404/非 JSON）。模型 id 非法时直接提示，不发请求。

### 6.2 共用字段（页签下方）

保存到（`EditBox` + [浏览…]，记住上次）、分段数（`NumericUpDown`，1–256，默认取设置值）、
「立即开始」勾选、代理（`RadioButton` 组：默认 / 直连 / 各条具名代理，限高 64 滚动；
`ComboBox` 在 MewUI 弹层里点不动）。**底部按钮区与校验提示区两页共用**，不要为每个协议各写窗口。

任务级代理：选中的代理在建任务时解析成 `ProxyRoute` 固化进任务，之后改设置不影响它；
「默认」= 跟随设置页的默认代理。HF 页拉清单与文件下载用同一个选中代理。

### 6.3 校验

- 链接页：URL 必须 `http/https` 绝对地址；多行时按钮文案不变，按行拆多个请求。
- HF 页：模型 id 合法 + 至少勾一个文件 + 保存目录存在可写；错误同时写页内状态行与底部红字。
- 保存目录必须存在且可写（失败即时提示红框 + 文案）。

V3 预留：再增加「种子文件 / 磁力」页，共用字段与按钮区不动。

## 8. 空态与错误态

- 空列表：居中图标 + 「把下载链接拖到这里，或点击新建」+ [新建下载] 按钮。
- 失败行：文件名下方直接显示错误文案（中文），Tooltip 为详细异常；提供 [重试]。
- 目录不可写：新建时阻断；运行中出现则任务转 `磁盘错误` 状态并保留 `.xdm-part`。

## 9. 可测试性约定（视图层断言依赖）

- 关键控件在构造时挂稳定的 `Name`，命名规范 `Part_Element`：
  `Main_TaskList`、`Main_StatusText`、`New_UrlBox`、`New_OkButton`（MewUI 里是 `Element.Name`）。
- 行内容不要靠"找控件"断言：`ListBox` 不为每行建元素，文案断言走
  `VisualTree.Texts()` 遍历可见元素。
- 所有图标按钮的文案必须落在 `AccessText`/`TextBlock` 上（中文动作名），既满足无障碍，
  也让 `VisualTree.Texts` 能取到。
- 禁止把状态文案硬编码在视图里：统一走 `TextFormat` / `DownloadStatusText`，便于测试断言中文文案。

## 11. 窗口外观（自绘标题栏 / 尺寸 / 图标）

系统 chrome 一律关掉，标题栏自己画：MewUI 的窗口默认无系统装饰（`Window.Title` 仍设，
任务栏与 Alt+Tab 用它）。拖动与双击最大化由 `WindowDrag.cs` 处理。

### 11.1 `MainWindow.BuildTitleBar()` / `Controls/TitleBarChrome.cs`

| 项 | 规格 |
|---|---|
| 高 | 30，底部 1px 分隔线（与 Neat Downloader 等第三方自绘标题栏同高，系统默认 32 偏厚） |
| 底色 | `#1F2B3B`（`XdmTitleBarBrush`） |
| 分隔线 | `#2C3A4E`（`XdmTitleBarBorderBrush`） |
| 前景 | `#E7EEF8`（`XdmTitleBarForegroundBrush`） |
| 左区 | 18×18 透明底 logo（`/Assets/xdm-logo.png`，白底与辉光已剥离，直接贴深色底板）+ 12px SemiBold 标题 |
| 右区 | 最小化 / 最大化 / 关闭，各 44×30，`Button.cap` 样式（无圆角无边框） |
| 按钮 hover | 约 `#26FFFFFF`；关闭键 hover `#C42B1C`、按下 `#E81123` |
| 交互 | 空白处按下即 `BeginMoveDrag`；双击切换最大化；最大化时最大化键变「还原」双框图标 |
| 属性 | `Title`（与 `Window.Title` 分开维护）、`ShowMaximize` / `ShowMinimize`（对话框两者都设 `False`） |

约束：

- 宿主窗口必须是 `WindowDecorations="BorderOnly"`，否则两层标题栏。
- 标题栏放在 `DockPanel.Dock="Top"` 的第一项；窗口根布局保持 `DockPanel`，不要改成 `Grid` 硬编码行。
- 标题与图标按钮的 `PointerPressed` 必须 `e.Handled = true`，否则点按钮会把窗口拖起来。

### 11.2 窗口尺寸

| 窗口 | 默认 | 最小 |
|---|---|---|
| 主窗口 | 1000×620 | 720×420 |
| 新建下载 | 620×600 | 620×600（固定，不可缩放） |
| 设置 | 620×640 | 540×580 |
| 关于 | 460×（内容自适应高） | 不可缩放 |
| 确认框（`ConfirmDialog`） | 440×（内容自适应高） | 不可缩放 |

对话框一律 `WindowStartupLocation="CenterOwner"` + `ShowInTaskbar="False"`，主窗口 `CenterScreen`。
`SizeToContent="Height"` 的对话框不要设 `Height`，否则内容会按固定高度拉伸。

### 11.3 图标资源

- 唯一来源是仓库根 `logo.png`（480×480，白底 + 蓝紫渐变箭头 + 光带），处理脚本 `tools/make-icons.ps1`：
  `pwsh tools/make-icons.ps1` 一次生成下面两个文件，改 logo 后重跑即可，**不要手工改产物**。
- 透明化规则：从四边洪泛「近白背景」（原图底色是 240~255 的渐变，不能用固定阈值一刀切）；
  箭头本体（min 通道 ≤ 200）保留原配色；中间那圈浅色辉光按白色混入比例给半透明并反合成去白，
  否则贴到深色标题栏上会浮出一圈白雾。alpha 再做一遍 3×3 均值消掉洪泛边界的碎齿，
  最后按内容包围盒裁正方形缩到目标尺寸。
- 界面内 logo：`src/Xdm.Ui.Mew/Assets/xdm-logo.png`（嵌入资源，256×256，**透明底**）：
  标题栏（18px）、关于窗口（52px）共用。
- exe / 任务栏图标：`src/Xdm.App.Mew/Assets/xdm.ico`（`ApplicationIcon`），同一透明底打包
  16/20/24/32/40/48/64/96/128/256 十个 PNG 压缩帧（手工拼 ICONDIR，256 帧在目录项里记 0）。
- 不要再用「白底圆角牌」：标题栏是深色，白块会显得像贴纸。

## 12. MewUI 实现约定（唯一实现）

`Xdm.Ui.Mew` 是同一套规范的 code-first 实现，**视觉对齐按截图验收**。下表是各规范项的实现手段
（右列是现行实现；左列是已删除的 Avalonia 版，仅作历史对照）：

| 规范项 | 原 Avalonia 实现（已删除） | 现行 MewUI 实现 |
|---|---|---|
| 颜色 / 尺寸 token | `Styles/Theme.axaml` 资源字典 | `MewTheme` 静态类（`MewThemeTests` 钉住色值与尺寸） |
| 标题栏 | `Controls/TitleBar.axaml` | `MainWindow.BuildTitleBar()`（`Border` + `PathShape` 矢量窗钮） |
| 对话框标题栏 | 各自 XAML | `Controls/TitleBarChrome`（四框共用） |
| 暗色标题栏上的按钮 | `Button.cap` 样式 | **不能用 `Button`**：模板背景压不住，深色底上会露浅色方块，必须 `Border` 自绘 hover |
| 右键菜单 | Fluent 默认（已是中文） | MewUI 自带英文 `Cut/Copy/Paste`，用 `Controls/EditBox.AttachMenu()` 换成中文并设 `CommandTarget` |
| 状态文案 | `DownloadStatusTextConverter` | 同一个转换器（`Xdm.Ui.Shared`），MewUI 侧只换取色（`BadgeStyle`） |
| 行内图标 | `PathIcon` + 资源 | `PathShape` + `Geometry.Parse`，**必须显式设 `StrokeThickness=1`**，否则笔画不显示 |

字号与间距按 §10；字体走系统默认（不引入外部字体）。
行高、标题栏高、状态栏高、左栏宽与 §10 表完全一致（`MewTheme` 里同名常量）。
